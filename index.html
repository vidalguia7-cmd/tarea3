1) Formas principales de conectar HTML con JavaScript

A) Script Interno (In-line / Embedded): Se escribe el código directamente dentro de una etiqueta <script> en el archivo HTML.

<script>
    console.log("Hola desde código interno");
</script>

B) Script Externo: Se vincula un archivo ejecutable .js independiente mediante el atributo src en la etiqueta <script>.

<script src=./js"script.js"></script>

2) ¿Cómo visualizar los resultados utilizando la consola del navegador?

  1. Abrir el archivo index.html en un navegador web (visual studio code).
  2. Abrir las herramientas de desarrollador presionando la tecla F12 o clic derecho en la página y seleccionar Inspeccionar.
  3. Ir a la pestaña llamada Consola (Console).
  4. Allí se visualizarán las salidas generadas por funciones como console.log(), así como errores o mensajes del sistema.

3) Variables en script.js: let y const

Una variable en script.js es un contenedor para almacenar datos e información.

  • let: Tiene alcance de bloque (block scope). Permite reasignar su valor pero no volver a declararla en el mismo ámbito.
  • const: Tiene alcance de bloque. Su valor es constante, por lo que no se puede reasignar ni redeclarar.

¿Cuál ya no se recomienda utilizar y por qué?
Ya no se recomienda utilizar var. Su uso causa problemas debido a su alcance no delimitado por bloques y al comportamiento de hoisting (elevación), lo cual puede sobrescribir variables accidentalmente y generar errores difíciles de depurar en el código.
