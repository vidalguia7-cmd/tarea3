Preguntas Teóricas

1) Existen dos formas principales de conectar un archivo HTML con JavaScript. Explique cuáles son estas 2 formas y proporcione un ejemplo básico de cada una.

Forma 1: Script Interno (In-line / Embedded)
Consiste en escribir código JavaScript directamente dentro del archivo HTML utilizando la etiqueta <script>.

<!-- Ejemplo Interno -->
<script>
    console.log("Hola desde el script interno");
</script>

Forma 2: Script Externo
Consiste en vincular un archivo independiente con extensión .js mediante el atributo src en la etiqueta <script>.

<!-- Ejemplo Externo -->
<script src="./js/script.js"></script>

2) Explique paso a paso cómo visualizar los resultados de JavaScript utilizando la consola del navegador.

  1. Abrir el navegador web (como Google Chrome, Firefox o Edge) y cargar la página HTML.
  2. Abrir las Herramientas de Desarrollador presionando la tecla F12 o las teclas Ctrl + Shift + I (o clic derecho en cualquier parte de la página y seleccionar Inspeccionar).
  3. Hacer clic en la pestaña Consola (Console).
  4. En la consola se mostrarán las salidas ejecutadas por comandos como console.log(), mensajes del sistema o errores de JavaScript.

3) Explique qué son las variables en JavaScript y cuál es la diferencia entre var, let y const. Incluya un ejemplo sencillo de cada una e indique cuál de estas formas ya no se recomienda utilizar actualmente y por qué.

Las variables son contenedores que nos permiten almacenar datos en la memoria para utilizarlos o modificarlos durante la ejecución del programa.

    3) Variables en JavaScript (var, let, const)

    Una variable guarda datos. Ejemplo: var a = 1; var a = 2; (permite re declarar), let b = 1; b = 2; (re sasigna), const c = 1; (fijo).

    Diferencia: var tiene alcance global/función, mientras que let y const tienen alcance de bloque.

    No recomendada: Ya no se usa var porque genera errores al sobrescribir variables globalmente; se debe usar let y const.
